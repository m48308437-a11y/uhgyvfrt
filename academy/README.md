# آکادمی ریاضی استاد علایی‌نسب — نسخه ۲ (پلتفرم واقعی فروش دوره)

## وضعیت پروژه (صادقانه)
| بخش | وضعیت |
|---|---|
| بک‌اند Node.js + PostgreSQL (احراز هویت، OTP، نقش‌ها، سفارش، زرین‌پال، آپلود چندبخشی ویدیو، لینک امضاشده، پیشرفت، تیکت، گزارش، لاگ) | ✅ کامل — ۲۰ تست خودکار پاس (`npm test`) |
| فرانت سایت (خانه، فروشگاه، صفحه دوره، سبد، پرداخت، ورود/ثبت‌نام/OTP/بازیابی، پنل دانش‌آموز، کلاس و پلیر، مقالات، پشتیبانی، دستیار) | ✅ ساخته و بیلد شد |
| رابط کاربری پنل مدیریت | ⚠️ فقط داشبورد آمار. صفحات مدیریت دوره/فصل/جلسه، آپلودر ویدیو، سفارش‌ها، کاربران، کوپن‌ها، محتوا هنوز رابط ندارند (API همه‌شان آماده و تست‌شده در `server/routes/admin.js`) |
| تست مرورگر واقعی (موبایل/دسکتاپ) و تست با زرین‌پال/پیامک واقعی | ❌ انجام نشده (Sandbox بدون اینترنت؛ درگاه با Mock تست شد) |

**تا تکمیل رابط مدیریت و تست واقعی، آماده انتشار نهایی نیست.**

## معماری
- فرانت: React 18 + Tailwind، RTL، Mobile-first، بدون Three.js/Recharts/mathjs (حجم JS اصلی ≈۲۱۵KB قبل از فشرده‌سازی؛ نسخه قبل ≈۳.۵MB).
- بک‌اند: Node.js 22 بدون فریم‌ورک، تنها وابستگی `pg`. توسعه/تست روی SQLite داخلی Node.
- انتخاب‌ها برای بازار ایران: درگاه **زرین‌پال v4**، پیامک **کاوه‌نگار یا SMS.ir**، ویدیو روی **Object Storage ابرآروان** (S3) با Presigned URL. Supabase/Firebase به‌دلیل تحریم و مشکل درگاه ایرانی انتخاب نشدند.

## اجرا (توسعه)
```
npm install
cp .env.example .env      # APP_SECRET را پر کنید
npm run seed:dev          # اسکیما + محتوای اصلی سایت + کدهای تخفیف نمونه
npm run create-admin -- --phone 09xxxxxxxxx --name "استاد علایی‌نسب"
npm run build && npm run dev   # http://localhost:3000  (کد OTP در لاگ سرور چاپ می‌شود)
npm test
```

## Production
1. PostgreSQL 16 → `DATABASE_URL`، سپس `npm run migrate -- --seed`.
2. `NODE_ENV=production`، `APP_ORIGIN=https://دامنه`، `APP_SECRET` (۴۸ بایت تصادفی).
3. سرور بدون تنظیمات امن بالا نمی‌آید (بررسی در `server/config.js`).
4. هاست پیشنهادی: لیارا یا ابرآروان (Node 22) پشت HTTPS؛ `npm run build && npm start`.

## درگاه پرداخت (زرین‌پال)
- نیازمند: نماد اعتماد (اینماد)، حساب شبا به نام صاحب کسب‌وکار، ثبت دامنه در پنل زرین‌پال، دریافت **Merchant ID**.
- ابتدا با `ZARINPAL_SANDBOX=true` تست کنید، سپس `false`.
- جریان: سفارش در سرور (قیمت فقط از دیتابیس) ← request ← StartPay ← callback ← **verify سرور‌به‌سرور** با مبلغ ذخیره‌شده ← فعال‌سازی دسترسی. Callback تکراری پردازش نمی‌شود؛ خطای ارتباطی سفارش را «در انتظار» نگه می‌دارد و مدیر با `POST /api/admin/orders/:n/reconcile` دوباره بررسی می‌کند.
- بازگشت وجه: در پنل زرین‌پال انجام دهید، سپس `refund` در پنل (دسترسی لغو می‌شود).

## پیامک
کاوه‌نگار: قالب Verify با توکن `%token%` بسازید → `KAVENEGAR_API_KEY`, `KAVENEGAR_TEMPLATE`. یا SMS.ir با پارامتر `CODE`.

## ویدیو
- `STORAGE_PROVIDER=s3` + باکت **خصوصی** ابرآروان. CORS باکت: اجازه `PUT, GET` از دامنه سایت و **ExposeHeaders: ETag**.
- آپلود چندبخشی مستقیم از مرورگر (بخش‌های ≥۱۰MB)، قابل ادامه، محدودیت حجم، بررسی نوع فایل از روی بایت‌های ابتدایی.
- پخش فقط با لینک امضاشده زمان‌دار پس از بررسی مجوز سرور + واترمارک شماره کاربر. فرمت پیشنهادی MP4/H.264. برای کیفیت چندگانه HLS، سرویس VOD ابرآروان پیشنهاد می‌شود (پیاده نشده).
- API آپلود: `POST /api/admin/videos` → `POST /:id/part-urls` → PUT بخش‌ها → `POST /:id/complete`؛ اتصال به جلسه با `PUT /api/admin/lessons/:id {videoId}`.

## امنیت
scrypt برای رمز، نشست HttpOnly/SameSite با توکن هش‌شده، CSRF (Origin + هدر سفارشی)، Rate limit، OTP هش‌شده با ۵ تلاش، CSP سخت‌گیرانه، کوئری‌های پارامتری، کنترل همه مجوزها در سرور، لاگ ممیزی.
