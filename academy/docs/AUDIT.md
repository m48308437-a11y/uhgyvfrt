# گزارش بررسی فایل قبلی و اصلاحات
فایل قبلی یک Artifact تک‌فایلی React (≈۳.۵MB) بود با این امکانات: صفحه اصلی، فروشگاه، صفحه دوره، سبد و کد تخفیف، پنل دانش‌آموز، پنل مدیریت، دستیار ریاضی، شبیه‌سازهای ریاضی، مقالات، FAQ، پشتیبانی. همه محتوا (۴ دوره، ۱۶ جلسه، مقالات، FAQ، برند) منتقل شد.

| مشکل | اصلاح |
|---|---|
| همه داده‌ها (کاربران، سفارش‌ها، نقش‌ها) در localStorage؛ هر کاربر می‌توانست خودش را مدیر کند | دیتابیس واقعی + نقش در سرور |
| «نشست آزمایشی» بدون رمز؛ سوئیچ به مدیر با یک کلیک | ثبت‌نام/ورود واقعی با OTP و scrypt |
| درگاه شبیه‌سازی‌شده؛ دکمه «پرداخت موفق» دسترسی می‌داد | زرین‌پال واقعی + verify سرور |
| مبلغ و کد تخفیف در مرورگر محاسبه می‌شد؛ انقضای کوپن و تخفیف بررسی نمی‌شد | محاسبه و اعتبارسنجی کامل در سرور |
| شماره سفارش تصادفی ۴ رقمی (برخورد) و تاریخ ثابت «۱۴۰۵/۰۷/۲۷ — اکنون» | شماره یکتا و زمان واقعی |
| «ویدیو» فقط انیمیشن بود؛ قفل درس‌ها فقط در فرانت | ویدیوی واقعی با لینک امضاشده و کنترل سرور |
| دوره ناموجود به اولین دوره fallback می‌شد | ۴۰۴ صحیح |
| سبد پیش‌فرض با یک دوره پر بود | سبد خالی |
| کتابخانه‌های سنگین (Three.js، Recharts، mathjs) | SVG سبک و موتور محاسباتی کوچک |
| اسکرول در `#root` با ارتفاع ثابت (مشکل iOS) | اسکرول طبیعی صفحه |
| وابستگی به قابلیت ai.infer مخصوص ClickUp | پروکسی سرور با کلید محرمانه + موتور محلی |
